# Doodle Theater: submission material

Everything for the Devpost entry that isn't code. The code
lives in the rest of this repo: `server/`, `tv/`, and the open-source rigger in `rig/`.

| Path | What |
|---|---|
| `devpost.md` | Devpost write-up draft (pick the `[IF ...]` variants that are true at submission) |
| `video-script.md` | Demo video script, shot list and Clipchamp cut list |
| `drawings-brief.md` | Brief for the drawings |
| `clips/` | Emulator recordings (`*_sound.mp4` have the Polly narration rebuilt in) |
| `voiceover/` | Polly voice-over, one MP3 per scene (`make_voiceover.py` regenerates) |
| `images/` | Diagram, end card, rig skeletons, cat walk, drawings photo |
| `cards/` | HTML sources for the diagram and end card (render with headless Chrome) |
| `record.py` | Records emulator clips and rebuilds their soundtrack from the server log |

Characters drawn by a neighbour's child, cleaned up with Gemini. Used with a parent's permission.
